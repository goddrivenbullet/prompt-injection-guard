prompt-injection-guard

Find the instructions hidden in the files your agent reads by itself.

Agents read rules files, skill definitions, tool descriptions and documentation without a human in the loop. Anything that looks like an instruction, hides text or carries an embedded command is a risk. This scans those places.

View on GitHub npm README

What it does

Ten patternsInstruction overrides, exfiltration attempts, role spoofing.
Invisible charactersZero-width and bidirectional control characters.
Directory scanningRules, skills, configs and documentation.
SanitisingStrip comments and invisible characters.

Usage

One fileprompt-injection-guard AGENTS.md
A whole directoryprompt-injection-guard --dir ~/.config/opencode
Clean itprompt-injection-guard --sanitise AGENTS.md

How it works

  1. Each pattern is matched over the whole text and counted.
  2. The first hit keeps an excerpt so you can see it in context.
